# Galleryの階層・詳細・文献の検証

2026-10-14、Chromium 153.0.8010.0。既存のGallery改善に追加した検証。

- ライブラリを折り畳み階層に整理。同じ階層は1分類だけ開き、移動後は現在の分類を示してメニューの積み重なりを防ぐ。コンポーネントは32の小さなパーツと64の用途のある部品。画面・構成は別の段階。用途フィルター、96部品、14 Series、Motion、Design Knowledge、既存の実験操作を保持。
- Seriesの一覧に6のandmオリジナルと8の公式資料参照を明示。参照のある実装もandmの解釈・独自補完を含み、公式製品の再配布・完全再現を意味しない。
- 画面構成3種・実験室7種 ×320/390/768/1280pxの40表示。Galleryのヘッダー・メニューを保ち、上位ページ/見本フレームに横はみ出しなし。画面構成の外枠を共通詳細に合わせて調整。
- タッチのカード遷移、ブラウザの戻る、画面構成で入力を保持した下部Series変更、Lab内の独立設定、文献の折り畳み・本文検索・直接章リンク、Motionの詳細ルートを確認。
- 文献の内容を5棚に分類。長い本文も各見出しを開いて読める。未確認資料の本文取得状態は変更しない。
- 既存96部品の672表示と代表6部品×14 Seriesの84表示（合計756）も再検証。文字200%、タッチのメニュー/用途/詳細、dialog取消・フォーカス復帰、入力/スクロール保持、hover/キーボード/Escape、実装項目の重複なし。横はみ出し・JavaScript例外なし。
- モバイルのメニュー・画面構成・文献、デスクトップの部品/Series一覧・Labをスクリーンショットで目視確認。
- build、token/source/coverage/design-knowledge監査、JS構文、diff check成功。

iOS/SafariやAndroidの実機、ソフトキーボード、支援技術は今回未検証。画面幅を変えたChromiumとタッチエミュレーションの結果を実機検証とは呼ばない。Libraryの既存画像は参考確認にのみ利用し、リポジトリに複製していない。mainへのマージは行わない。

再現用: `scripts/check-gallery-mobile.mjs`, `scripts/check-gallery-navigation.mjs`。Playwrightと実Chromiumを環境変数 `PLAYWRIGHT_MODULE` / `CHROMIUM_EXECUTABLE_PATH` で指定する。テストは独立したローカル配信環境で実施し、確認サイトの公開状態は別に検証する。
