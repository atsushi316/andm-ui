プロトタイプ用テーマを選ぶ

Series 本機能ではなく、デモ用親スコープ（Token remapping）です。用途に合う class を親に付けて試してください。テーマを増やすときは同じパターンでパネルを追加します。

Baseline（Default）

いつ使うか: 標準の製品 UI・一般アプリの出発点

:root 既定。radius-md・標準 press。追加 class 不要。

（スコープなし）

Expressive

いつ使うか: 強調・遊び・マーケティング寄りのプロトタイプ

pill shape・強めの press morph・expressive easing（空間のみ）。

andm-series--expressive

デジタル庁寄り

いつ使うか: 行政・公共系プロトタイプ、高コントラスト・可読性優先

Blue 900・角丸 8px・Noto Sans JP・黄フォーカス環。公式再配布ではない模倣。

andm-series--digital-gov

Expressive detail

M3 Expressive 寄りの shape（丸み・非対称）と強調。既存 variant 名はそのまま。ホバー／押下で shape morph と spatial motion を確認。

Shape & emphasis

既定は pill。任意で andm-btn--shape-asymmetric（角の対角差）。

デジタル庁寄り detail

親に andm-series--digital-gov。色・角丸・タイポを DADS の公開仕様に寄せた Token remapping。variant 名はそのまま。

Filled / Outlined / Text

Primary #0017C1、radius 8px、黄フォーカス（Tab で確認）。Tab でフォーカス環を確認してください。

デジタル庁テーマについて: 本デモの andm-series--digital-gov は デジタル庁デザインシステム の公開ドキュメントに寄せた模倣テーマです。公式パッケージ（例: @digital-go-jp/design-tokens）やブランド資産の再配布ではありません。本番の行政サイトでは公式アセットとガイドラインを確認してください。詳細は DESIGN.md も参照。
