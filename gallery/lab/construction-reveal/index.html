どんなときに使う？

新しいダッシュボードの初回表示、AIが作ったUIのお披露目、構造を見せたいデモに。頻繁に使う画面では「短く」か「演出をオフ」で待ち時間を減らします。

実際の読み込みやAI生成が終わるまで待たせる場合は、実際の状態を別に通知してください。この演出から完了率を推測させません。

取り付け方

既存HTMLを保持し、reveal.jsが部位の位置から輪郭を描きます。初期値は完成形。演出中だけ操作を止め、「完成形を表示」で即座に戻れます。ライブラリの公式仕様を変えるものではありません。

import { createConstructionReveal } from './reveal.js';
const effect = createConstructionReveal(card);
await effect.play({ style: 'blueprint', duration: 1800 });
