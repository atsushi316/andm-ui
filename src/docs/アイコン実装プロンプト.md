# アイコン実装プロンプト

## 概要

andm-uiのアイコンシステムは、`src/assets/icons/*.ts`から動的に読み込まれるシンプルなデータファイル形式です。新しいアイコンを追加する際は、このプロンプトに従って実装してください。

## 実装手順

### 1. SVGデータからパスデータを抽出

Google Material Iconsやその他のSVGアイコンから、`<path d="...">`の`d`属性の値を抽出します。

**例：Material Iconsから`favorite`アイコンを取得**

```html
<!-- Material Iconsの24x24版SVG -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor">
  <path d="M12 21.35l-1.45-1.32C5.4 15.36 2 12.28 2 8.5 2 5.42 4.42 3 7.5 3c1.74 0 3.41.81 4.5 2.09C13.09 3.81 14.76 3 16.5 3 19.58 3 22 5.42 22 8.5c0 3.78-3.4 6.86-8.55 11.54L12 21.35z"/>
</svg>
```

**抽出するパスデータ：**
```
M12 21.35l-1.45-1.32C5.4 15.36 2 12.28 2 8.5 2 5.42 4.42 3 7.5 3c1.74 0 3.41.81 4.5 2.09C13.09 3.81 14.76 3 16.5 3 19.58 3 22 5.42 22 8.5c0 3.78-3.4 6.86-8.55 11.54L12 21.35z
```

### 2. アイコンファイルを作成

`src/assets/icons/`ディレクトリに新しい`.ts`ファイルを作成します。

**ファイル名の規則：**
- アイコン名をそのまま使用（例：`favorite.ts`）
- ハイフンは使用可能（例：`chevron-down.ts`）
- ファイル名がそのままアイコン名になります

**単一パスの場合：**

```typescript
// src/assets/icons/favorite.ts
// パスデータ（24x24版、strokeベース）
export const pathData = "M12 21.35l-1.45-1.32C5.4 15.36 2 12.28 2 8.5 2 5.42 4.42 3 7.5 3c1.74 0 3.41.81 4.5 2.09C13.09 3.81 14.76 3 16.5 3 19.58 3 22 5.42 22 8.5c0 3.78-3.4 6.86-8.55 11.54L12 21.35z" as const;
```

**複数パスの場合：**

  "M12.22 2h-.44a2 2 0 00-2 2v.18a2 2 0 01-1 1.73l-.43.25a2 2 0 01-2 0l-.15-.08a2 2 0 00-2.73.73l-.22.38a2 2 0 00.73 2.73l.15.1a2 2 0 011 1.72v.51a2 2 0 01-1 1.74l-.15.09a2 2 0 00-.73 2.73l.22.38a2 2 0 002.73.73l.15-.08a2 2 0 012 0l.43.25a2 2 0 001 1.73V20a2 2 0 002 2h.44a2 2 0 002-2v-.18a2 2 0 011-1.73l.43-.25a2 2 0 012 0l.15.08a2 2 0 002.73-.73l.22-.39a2 2 0 00-.73-2.73l-.15-.08a2 2 0 01-1-1.74v-.5a2 2 0 011-1.74l.15-.09a2 2 0 00.73-2.73l-.22-.38a2 2 0 00-2.73-.73l-.15.08a2 2 0 01-2 0l-.43-.25a2 2 0 01-1-1.73V4a2 2 0 00-2-2z",

### 3. 自動読み込み

`import.meta.glob`により、新しいファイルは自動的に読み込まれます。**`icons.ts`の変更は不要**です。

### 4. 使用例

```vue
<template>
  <!-- アイコン名はファイル名（拡張子なし） -->
  <Icon name="favorite" size="md" aria-label="Favorite icon" />
  
  <!-- Buttonコンポーネントで使用 -->
  <Button icon-name="favorite">お気に入り</Button>
  
  <!-- IconButtonで使用 -->
  <IconButton icon-name="favorite" aria-label="Add to favorites" />
</template>
```

## 重要な注意点

### viewBoxの確認

- **必須：24x24版のSVGを使用してください**
- 現在の実装は`viewBox="0 0 24 24"`を使用しています
- 他のサイズ（例：`0 -960 960 960`）の場合は、パスデータの変換が必要です

### fill vs stroke

- 現在の実装は`stroke="currentColor"`を使用（アウトライン形式）
- Material Iconsは通常`fill`ベースですが、パスデータはそのまま使用可能
- 見た目が異なる場合は、stroke用のパスデータに変換するか、`Icon.vue`の設定を調整

### ファイル名とアイコン名

- ファイル名がそのままアイコン名になります
- `favorite.ts` → `<Icon name="favorite" />`
- `chevron-down.ts` → `<Icon name="chevron-down" />`

### 型安全性

- TypeScriptの型推論により、`IconName`型が自動的に更新されます
- StorybookのControlsで`select`コントロールを使用すると、利用可能なアイコン名が表示されます

## 検証方法

1. **Storybookで確認**
   ```bash
   npm run storybook
   ```
   - 「Atoms/Icon」ページで新しいアイコンが表示されることを確認

2. **型チェック**
   ```bash
   npm run type-check
   ```
   - 型エラーがないことを確認

3. **実際の使用**
   ```vue
   <Icon name="新しいアイコン名" />
   ```
   - 正しく表示されることを確認

## トラブルシューティング

### アイコンが表示されない

- ファイル名が正しいか確認（拡張子は`.ts`）
- `pathData`が正しくexportされているか確認
- `viewBox="0 0 24 24"`のSVGを使用しているか確認

### 見た目がおかしい

- Material Iconsの24x24版を使用しているか確認
- fillベースのアイコンは、strokeベースに変換が必要な場合があります

### 型エラーが出る

- `as const`が正しく付いているか確認
- `pathData`の型が`string | string[]`になっているか確認
