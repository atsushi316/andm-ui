# Gallery の改善根拠

確認日：2026-10-07。目的は携帯から部品を探し、表現を比べ、HTML と根拠を確認すること。研究の測定値を Core の寸法にしない。

検索・部品カード・シリーズ用 select は、携帯での「探す→比較→使う」を短くする andm 独自の設計判断。上記資料がこの Gallery 配置を指定しているわけではない。文学・学術論文の未読本文や数値から正解を導出していない。

## 変更

- 大量の説明リンクと完成状況を、部品一覧へ置き換える。日本語・英語の検索で直接移動。
- 携帯ではナビを初期状態で閉じる。本文を見る際の画面占有を減らす。
- シリーズを select から選ぶ。一覧ボタンも折りたたみ内に残す。前のシリーズは端末内に記憶。
- 部品ページに先頭の HTML 見本とコピーを追加。操作 JS は消費側の責務と表示。
- Series 分析を Gallery 内で読めるようにする。生の Markdown ファイルへ飛ばさない。
- Chip / FAB は独自仕様を表示し、公式の確認範囲と分ける。
- 未分類の Component-local トークンにも一覧の入口を用意。

## 境界

Workspace の CSS は Gallery のレイアウト・ナビ・説明だけ。製品の andm-* の値は変更しない。Series は見本の親スコープだけ。研究表示は人間が資料を読む導線であり、研究ファイルの数値をトークンとして読み込む仕組みではない。

## 検証

Chromium で日本語表示のスクリーンショットを確認。30部品のページとホーム・トークン・文献・シリーズの代表ページを、320 / 390 / 800 / 1280px 幅で確認し、ページ全体の横はみ出しは0件。検索・分類・携帯メニュー/Escape・Series 切替・HTML生成・出典読書ビュー・Chip選択・Tabs矢印操作・ラボのダイアログと取消を確認。FAB は14シリーズで通常サイズの最小高さと変形が混入しないことを確認。ページの JavaScript エラーは0件。

`npm run audit:tokens` は153定義、必須の未定義参照なし。JS構文チェックと差分の空白チェックも成功。

Safari / iOS 実機、支援技術、全状態のコントラスト、長期利用の心地よさは未検証。全端末のアクセシビリティ適合を保証するものではない。

## 2026-10-08：閲覧と比較を中心に再設計

前回の横幅チェックは、入力・操作の上下ずれや「見本が画面下に押し出される」問題を検出できなかった。使いやすさを証明した扱いを訂正する。

利用者は主に、欲しい部品を探し、同じ部品を見たまま表現を比較し、採用するHTMLと根拠を確認する。順序を「部品を選ぶ → 見本を操作 → 同じ位置でシリーズ切替 → 必要時にHTML/出典」とする。

- Seriesの大きい先頭カードと重複した一覧をやめ、常駐する小さい比較ドックにNative select + 前へ/次へを置く。DOM上は見本の前でキーボードから早く到達できる。選択名を常時見せ、移動先や現在の部品を変えずに比較する。
- 検索入力・絞り込み・開閉状態・閲覧位置はシリーズ変更で初期化しない。製品見本だけを変更し、GalleryのChromeは一定にする。
- コピーと根拠は見本の後へ移し、説明は必要時に開く。部品一覧への戻る導線を見出し前に置く。
- 一覧の分類は日本語の用途（入力・操作／ナビゲーション／文字・記号／面・情報表示／状態・通知／重ねて表示）にする。検索フォームのサムネイルは検索ボタン単体ではなく入力欄を含む部品を見せる。
- 固定操作は最小限の中立なChromeとし、見本の主操作と強調が競合しないようにする。本文末尾に余白、safe-area対応、scroll-paddingを確保。

このドックはGalleryの比較操作であり、DADS製品のBottom navigationの再現ではない。DADSはBottom navを非推奨としているため、製品部品のDADS表示には注意と代替を明示する。Spectrum Attention hierarchyの「注意の強さを使い分ける」概念を見本優先の判断に参照した。具体的な浮動ドックの配置はandm独自の設計。

検証：Searchは14Series × 320/390/800/1280 × 文字100%/200%=112組で、同じ行なら下端が揃い、折返し時は重ならないことを座標で検証。58部品 × 14Series × 390/1280=1,624組で表示・ページ横はみ出し・JS例外を確認。携帯/デスクトップのスクリーンショットを目視。シリーズ変更後の検索内容・スクロール・次の部品への選択継承、DADS注意、Menu/Popover/TooltipのEscape・関連付け・focusを確認。iOS実機、実ユーザーによる使いやすさ評価は未実施。
