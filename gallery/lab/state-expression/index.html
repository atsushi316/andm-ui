文献と設計判断

文献は用途と制約の根拠です。このページ独自の色・形・速度が最適であると実証するものではありません。

Carbon / Progress bar
進捗を計算できる場合と、残りが分からない場合を分ける。進捗不明の例に架空のパーセントを表示しません。
Tailwind CSS / Animation
スケルトンに明滅を使う例。明滅と光が流れる表現を別候補として比較します。後者は独自案です。
MDN / AnalyserNode
音声の時間領域・周波数領域の可視化。本実験は固定の模擬振幅で、実際のマイク入力ではありません。波形とレベル表示は読み取れる情報が異なります。
W3C / Status messages
状態変化は共通の文字表示でも通知。カードごとの繰り返し読み上げを避けます。
W3C / Animation from interactions
OSの動きを減らす設定と、ページ内の演出停止に対応。静止しても状態・数値は更新します。
Harrisonほか / Rethinking the Progress Bar（UIST 2007）
進み方によって待ち時間の感じ方が変わる研究。実際の処理時間や理解しやすさとは別の評価です。本ラボは進捗を共通に保ちます。
Harrisonほか / Faster Progress Bars（CHI 2010）
見た目の動きと知覚される時間を比較。特定の演出があらゆる状態で優れるという根拠にはしません。
