# モーション実装ガイド

Material Design 3 (M3) Motionガイドラインに基づいた、andm-uiコンポーネント実装時のモーション適用ルールです。

## 📚 参考リソース

- [M3 Motion Overview](https://m3.material.io/styles/motion/overview/how-it-works)
- [M3 Motion Specs](https://m3.material.io/styles/motion/overview/specs)
- [M3 Motion: Applying Easing and Duration](https://m3.material.io/styles/motion/easing-and-duration/applying-easing-and-duration)
- [M3 Motion: Easing and Duration Tokens Specs](https://m3.material.io/styles/motion/easing-and-duration/tokens-specs)

---

## 🎯 基本原則

1. **トークン駆動**: すべてのモーションは`src/styles/tokens.css`で定義されたトークンを使用する
2. **一貫性**: 同じ操作には同じduration/easingを適用する
3. **アクセシビリティ**: `prefers-reduced-motion`に対応する
4. **パフォーマンス**: 過度なアニメーションを避け、必要最小限のモーションを実装する

---

## 📦 利用可能なトークン

### Duration（継続時間）

```css
--andm-motion-duration-short1: 50ms; /* プレス操作のフィードバック（押下時の即時反応） */
--andm-motion-duration-short2: 100ms; /* ホバー/フォーカスの表示/解除 */
--andm-motion-duration-short3: 150ms; /* エレベーション変化、リリースアニメーション、状態変更 */
--andm-motion-duration-short4: 200ms; /* Extended FABの展開、ラベル表示/非表示 */
```

### Easing（イージングカーブ）

```css
--andm-motion-easing-standard: cubic-bezier(
  0.4,
  0,
  0.2,
  1
); /* 標準的なアニメーション（押す・リリース・切り替え） */
--andm-motion-easing-decelerate: cubic-bezier(
  0,
  0,
  0.2,
  1
); /* 出現する要素、ホバー時の拡大 */
--andm-motion-easing-accelerate: cubic-bezier(
  0.4,
  0,
  1,
  1
); /* 要素が消えるとき、押す操作の終了 */
--andm-motion-easing-sharp: cubic-bezier(
  0.4,
  0,
  0.6,
  1
); /* 強調・アクセントモーション */
```

## 🎨 モーション適用ルール

### 1. プレス操作（:active）

**用途**: ボタンやインタラクティブ要素を押下した時の即時フィードバック

**ルール**:

- **Duration**: `short1` (50ms)
- **Easing**: `accelerate`
- **Transform**: `scale(0.96)`
- **適用プロパティ**: `transform`, `box-shadow`

**実装例**:

```css
.button:active:not(:disabled):not([aria-disabled="true"]) {
  transform: scale(0.96);
  transition:
    transform var(--andm-motion-duration-short1)
      var(--andm-motion-easing-accelerate),
    box-shadow var(--andm-motion-duration-short1)
      var(--andm-motion-easing-accelerate);
}
```

### 2. リリース操作（:active解除時）

**用途**: プレス状態から通常状態への復帰

**ルール**:

- **Duration**: `short2` (100ms)
- **Easing**: `standard`
- **適用プロパティ**: `transform`, `box-shadow`

**実装例**:

```css
.button {
  transition:
    transform var(--andm-motion-duration-short2)
      var(--andm-motion-easing-standard),
    box-shadow var(--andm-motion-duration-short2)
      var(--andm-motion-easing-standard);
}
```

### 3. ホバー/フォーカス操作（:hover, :focus-visible）

**用途**: マウスホバーやキーボードフォーカス時の視覚的フィードバック

**ルール**:

- **Duration**: `short2` (100ms)
- **Easing**: `decelerate`
- **適用プロパティ**: `box-shadow`, `background-color`, `color`, `border-color`

**実装例**:

```css
.button:hover:not(:disabled):not([aria-disabled="true"]) {
  box-shadow: var(--andm-elevation-hover);
  transition:
    box-shadow var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate),
    background-color var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate);
}
```

### 4. 状態変更（選択状態など）

**用途**: 選択状態の切り替え、トグル状態の変化

**ルール**:

- **Duration**: `short3` (150ms)
- **Easing**: `standard`
- **適用プロパティ**: `background-color`, `color`, `border-color`

**実装例**:

```css
.button--selected {
  background-color: var(--andm-color-selected-container);
  color: var(--andm-color-on-selected-container);
  transition:
    background-color var(--andm-motion-duration-short3)
      var(--andm-motion-easing-standard),
    color var(--andm-motion-duration-short3) var(--andm-motion-easing-standard);
}
```

### 5. 形状変化（Shape Morphing）

**用途**: Extended FABの展開/縮小、ラベルの表示/非表示

**ルール**:

- **Duration**: `short4` (200ms)
- **Easing**: `standard`
- **適用プロパティ**: `border-radius`, `width`, `padding`, `opacity`

**実装例**:

```css
.fab--extended {
  width: auto;
  padding: 0 var(--andm-fab-extended-padding-x);
  border-radius: var(--andm-radius-btn);
  transition:
    border-radius var(--andm-motion-duration-short4)
      var(--andm-motion-easing-standard),
    width var(--andm-motion-duration-short4) var(--andm-motion-easing-standard),
    padding var(--andm-motion-duration-short4)
      var(--andm-motion-easing-standard);
}
```

### 6. Overlay表示（::before疑似要素）

**用途**: ホバー/プレス時のoverlay表示

**ルール**:

- **ホバー時**: `short2` + `decelerate`
- **プレス時**: `short1` + `accelerate`
- **リリース時**: `short2` + `standard`
- **適用プロパティ**: `opacity`

**実装例**:

```css
.button:hover:not(:disabled):not([aria-disabled="true"])::before {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--andm-overlay-hover);
  border-radius: inherit;
  pointer-events: none;
  transition: opacity var(--andm-motion-duration-short2)
    var(--andm-motion-easing-decelerate);
}

.button:active:not(:disabled):not([aria-disabled="true"])::before {
  background: var(--andm-overlay-active);
  transition: opacity var(--andm-motion-duration-short1)
    var(--andm-motion-easing-accelerate);
}
```

## 🧩 コンポーネントタイプ別ガイドライン

### Button / IconButton

**基本transition**:

```css
.button {
  transition:
    transform var(--andm-motion-duration-short2)
      var(--andm-motion-easing-standard),
    box-shadow var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate),
    background-color var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate),
    color var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate),
    border-color var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate);
}
```

**プレス時**:

- `transform: scale(0.96)`
- `short1` + `accelerate`

**ホバー時**:

- `box-shadow`の変化（elevated variant）
- `short2` + `decelerate`

### FAB (Floating Action Button)

**基本transition**:

```css
.fab {
  transition:
    transform var(--andm-motion-duration-short2)
      var(--andm-motion-easing-standard),
    box-shadow var(--andm-motion-duration-short2)
      var(--andm-motion-easing-decelerate),
    border-radius var(--andm-motion-duration-short4)
      var(--andm-motion-easing-standard),
    width var(--andm-motion-duration-short4) var(--andm-motion-easing-standard),
    padding var(--andm-motion-duration-short4)
      var(--andm-motion-easing-standard);
}
```

**Extended FAB展開時**:

- `border-radius`: 50% → 角丸矩形
- `width`: 固定値 → auto
- `short4` + `standard`

### ButtonGroup (Connected)

**選択状態の切り替え**:

```css
.group--connected > * {
  transition: border-color var(--andm-motion-duration-short3)
    var(--andm-motion-easing-standard);
}
```

## ♿ アクセシビリティ

### prefers-reduced-motion対応

すべてのモーション実装で、`prefers-reduced-motion: reduce`に対応する必要があります。

**実装例**:

```css
@media (prefers-reduced-motion: reduce) {
  .button {
    transition: none;
  }

  .button:active:not(:disabled):not([aria-disabled="true"]) {
    transform: none;
  }
}
```

**ルール**:

- `transition: none`でモーションを無効化
- `transform`などの視覚的変化も無効化
- 機能的な変化（色の変更など）は維持

## 🚫 避けるべき実装

### ❌ 悪い例

```css
/* 直値を使用 */
.button {
  transition: transform 0.2s ease;
}

/* 不適切なduration */
.button:active {
  transition: transform 300ms ease;
}

/* 不適切なeasing */
.button:hover {
  transition: transform 100ms ease-in-out;
}
```

### ✅ 良い例

```css
/* トークンを使用 */
.button {
  transition: transform var(--andm-motion-duration-short2)
    var(--andm-motion-easing-standard);
}

/* 適切なduration/easing */
.button:active {
  transform: scale(0.96);
  transition: transform var(--andm-motion-duration-short1)
    var(--andm-motion-easing-accelerate);
}

.button:hover {
  transition: transform var(--andm-motion-duration-short2)
    var(--andm-motion-easing-decelerate);
}
```

## 🔍 トラブルシューティング

### モーションが適用されない

1. **トークンが定義されているか確認**

   - `src/styles/tokens.css`に必要なトークンが定義されているか

2. **CSSの読み込み順序を確認**

   - `src/style.css`または`.storybook/preview.ts`にCSSファイルがimportされているか

3. **セレクタの優先度を確認**
   - より具体的なセレクタが上書きしていないか

### モーションが滑らかでない

1. **適切なduration/easingを使用しているか確認**

   - プレス時: `short1` + `accelerate`
   - ホバー時: `short2` + `decelerate`
   - 状態変更: `short3` + `standard`

2. **複数のtransitionが競合していないか確認**
   - 同じプロパティに複数のtransitionが定義されていないか

## 🎯 まとめ

1. **常にトークンを使用**: 直値は避け、`var(--andm-motion-*)`を使用
2. **操作タイプに応じたduration/easingを選択**: プレス/ホバー/状態変更で使い分け
3. **アクセシビリティを考慮**: `prefers-reduced-motion`に対応
4. **一貫性を保つ**: 同じ操作には同じモーションを適用

これらのルールに従うことで、M3 Motionガイドラインに準拠した、一貫性のあるモーション実装が可能になります。
