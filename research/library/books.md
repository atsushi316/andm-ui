# 書籍

通読して判断の語彙が残るものだけを置いた。すべて **古典** とする。いまも改訂版が売られていても、生きた規格ではない。

この作業で章本文を開いた書籍はない。Atomic Design だけ、著者サイトの冒頭を開いた。他は未検証である。未検証の項目に、頁番号、図版の寸法、推奨ピクセルは書かない。優先度は編集メモであり、Core の推奨値ではない。

## The Design of Everyday Things

| 項目 | 内容 |
| --- | --- |
| 種別 | 古典 |

| URL | 出版社の現行版を確認する。今回は書誌ページを開いていない |

### 何について書かれているか

未検証。記憶では、ドアやコンロのような日常物を材料に、人がどう行為を探索し、結果を理解するかを論じた本である。アフォーダンス、シグニファイア、対応づけ、フィードバック、概念モデル、実行と評価のずれ、が中心の語彙として広く参照される。改訂版はシグニファイアの語を前に出し、当初のアフォーダンスの使い方を著者自身が修正している、という理解で読まれている。学術側の短い起点は [メンタルモデル](academic.md#norman-1983) と [アフォーダンスと慣習](academic.md#norman-1999)。

### UIデザインシステムとの関連

部品が「押せるように見える」ことと、押したあと状態が分かることと、利用者の頭の中のモデルがシステムのモデルとずれていないことを、別々に点検する。見た目トークンの根拠本ではない。

### なぜ読む価値があるか

デザインシステムの一貫性を、認知の語で説明できる最短の古典だからである。改訂版と初版で用語がずれているので、引用するときは版を固定する。

### 確認

未検証。

## The Psychology of Human-Computer Interaction

| 項目 | 内容 |
| --- | --- |
| 種別 | 古典 |
| 著者/組織 | Stuart K. Card、Thomas P. Moran、Allen Newell |
| 年 | 1983 |
| 分野 | HCI、認知モデリング |
| 無料で読めるか | 購入 |
| 優先度 | 高。編集メモであり、Core の推奨値ではない |
| URL | 書誌は Lawrence Erlbaum、1983。今回は開いていない |

### 何について書かれているか

未検証。記憶では、人間を情報処理系として近似し、Model Human Processor、GOMS、キー操作水準の予測を提示した本である。熟練した操作の時間を、知覚・認知・運動の概算で見積もる、という工学的な HCI の起点である。見積もりのミリ秒は、当時の概算であり、現行のモーション duration ではない。本文を開いていないので、定数は書かない。

### なぜ読む価値があるか

HCI を認知の近似モデルとして扱った古典で、後の Fitts の HCI 応用や、タスク分析の前提を辿れるからである。

### 確認

未検証。定数は意図的に書いていない。

## Atomic Design

| 項目 | 内容 |
| --- | --- |
| 種別 | 古典 |
| 著者/組織 | Brad Frost |
| 年 | 2016 |
| 分野 | デザインシステム、UI の階層 |
| 無料で読めるか | 著者サイトで全文が公開されている |
| 優先度 | 高。編集メモであり、Core の推奨値ではない |
| URL | https://atomicdesign.bradfrost.com/ |

### 何について書かれているか

サイトの冒頭を開いた。より多くの利用者、文脈、ブラウザ、装置、画面サイズにインターフェースを出さねばならない、という状況に対し、デザインシステムが品質と一貫性を速く届ける、とある。本は、UI を階層として考える方法、パターンライブラリが有効である条件、デザインと開発の作業の変え方を扱う、と冒頭は要約する。

化学の比喩による具体的な階層の名前は、サイト冒頭のこの段落には列挙されていない。記憶では atoms、molecules、organisms、templates、pages として知られる。その階層の定義は各章にあり、この作業では章を開いていないので、定義文は未検証として扱う。比喩を組織図やフォルダ名にそのまま固定すると、本が警告している硬さに戻る、という読み方が後年の著者の発言でも知られている。その発言も今回は開いていない。

### UIデザインシステムとの関連

小さい部品から画面を組み立てる語彙の代表である。階層の段数をトークンの層数と同一視しない。andm の CSS とコンポーネントのフォルダ構成は、この本の目次ではない。

### なぜ読む価値があるか

全文が無料で、デザインシステムを「画面の分解」として説明した、いまも引用される一次の本だからである。章の定義は、使うときにサイトで読み直す。

### 確認

一部確認。サイト冒頭のみ。章本文は未読。階層の固有名詞は記憶であり未検証。
