# Fluent 2 の確認範囲

2026-10-07 に https://fluent2.microsoft.design/shapes の本文を再確認。既存の Series は shapes / typography を参考にする。

- shapes は Rectangle / Circle / Pill / Beak を説明する。Pill はタグ・キーワード・リスト内の選択にも使われる。
- shapes の表は Buttons / dropdown の Medium を 4px、Large buttons を 8px とする。
- これは Chip / FAB 固有の仕様表ではない。今回、それらの高さ・余白・モーションの数値は採用しない。
- typography は今回本文を取り直していない。既存の字の対応付けを変更しない。

Chip / FAB は独自仕様。Fluent の色・書体などを継承しても公式部品の再現とは表示しない。
