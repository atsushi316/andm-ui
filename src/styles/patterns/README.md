# Pattern

複数のカテゴリを組み合わせ、一つのユーザータスクを終える UI。

SearchForm や FilterBar などがここに入る。単一の Button は Control。シリーズ（`series/`）は見た目の言語であり、Pattern ではない。

モーションの型（highlight / lift / compress / morph）も、ここには置かない。

`compositions.css` — Search / Filter / Field / Actions / Navigation / Toolbar / Resource / Empty / Loading。Native HTML API、動作例はgallery/compositions.js。[仕様と出典](../../../docs/COMPOSITION-SOURCES.md)。
