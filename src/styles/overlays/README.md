# Overlay

今の画面の上に、一時的に出す UI。

- `dialog.css` — `.andm-dialog`（native `<dialog>`。開閉は Gallery の短いスクリプト）
- `tooltip.css` — `.andm-tooltip`（hover と focus-within。別のポップアップ部品にはしない）
- `drawer.css` — `.andm-drawer`（端に出す native `<dialog>`）
- `popover.css` — `.andm-popover`（クリックで開き、中で操作できる）

ページ内の面は Container。
